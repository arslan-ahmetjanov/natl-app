Частые ошибки

Что проверять в первую очередь, когда прогон не идёт.

natl: команда не найдена

npm install -g @natl/cli @natl/adapter-playwright
npm prefix -g
natl --version

Ошибки браузера и Chromium

npx playwright install chromium
npx playwright install --with-deps chromium

FAIL … assert или элемент не найден

  • Селектор всё ещё правильный?
  • Предпочитайте устойчивый #id
  • Смотрите папку artifacts/: там скриншоты и трассы

Отступы в YAML

- fill: "#email"
  with: $user

HTTP-примеры зависают

node stubs/echo-server.mjs
natl run http_only.yaml

natl engines
