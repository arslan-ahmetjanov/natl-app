# Architecture Decision Records

Короткие записи о решениях, которые дорого менять. Формат: контекст, решение, следствия. Одна запись — один файл `NNNN-краткое-имя.md`.

| № | Решение | Статус |
|---|---|---|
| 0001 | Тесты хранятся в YAML, а не в JSON workspace | принято (см. `2026-11-13-mvp.md`) |
| 0002 | UI — десктоп на Electron, а не веб и не расширение | принято |
| 0003 | Тесты, история прогонов и настройки — файлы, без базы данных | принято |
| 0004 | Движок вызывается как библиотека (`runNatlFile`), без дочерних процессов | принято |
| 0005 | Провайдер LLM за интерфейсом, локальные модели поддерживаются | принято |
| 0006 | GitHub-авторизация через device flow, токен в Credential Manager | волна 2 |

Файлы записей появляются по мере того, как решение перестаёт быть очевидным из кода.
