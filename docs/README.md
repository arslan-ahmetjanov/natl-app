# Документация проекта

Сайт документации живёт отдельно: **https://arslan-ahmetjanov.github.io/natl-site/**
и собирается из репозитория `natl-site`. Копий страниц здесь нет, чтобы не
расходились версии.

Инженерные документы остаются в этом репозитории:

- `design/` — позиционирование, границы MVP;
- `adr/` — принятые решения;
- `compliance/` — права, NDA, подпись сборки;
- `versioning.md` — схема версий;
- `format.md` — формат папки проекта: файлы, имена, совместимость;
- `roadmap-1.0.md` — что осталось до 1.0.0;
- `repositories.md` — карта репозиториев.
