# Участие в разработке NATL IDE

Здесь живёт приложение. Движок — в отдельном репозитории
[`natl`](https://github.com/arslan-ahmetjanov/natl): язык, интерпретатор,
CLI, адаптеры.

## Что менять где

| Задача | Репозиторий |
|---|---|
| Интерфейс, запись, экраны, прогон | этот (`natl-ide`) |
| Язык, интерпретатор, отчёты, CLI | [`natl`](https://github.com/arslan-ahmetjanov/natl) |
| Документация и сайт | [`natl-site`](https://github.com/arslan-ahmetjanov/natl-site) |

Если для приложения нужно поведение движка — сначала изменение в `natl`,
публикация версии, потом обновление зависимости здесь. Править копию движка
внутри приложения нельзя: копий нет.

## Разработка

```
cd apps/desktop
npm install
npm start
```

## Проверки перед PR

```
cd apps/desktop
npm run lint --prefix frontend
npm run test:natl
npm run smoke:natl
```

## Задачи

Работа идёт через бэклог: GitHub Project NATL. Перед PR должна быть задача,
после — ссылка на неё в описании.

## Стиль

- Интерфейс: функциональные компоненты, один компонент — одна задача.
- Ошибки: человеческий текст через `utils/errors.js`, технический — в журнал.
- Строки: русский как основа, переводы через `utils/i18n.js`.
