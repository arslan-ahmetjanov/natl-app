# NATL Desktop

Приложение для записи и запуска UI-тестов. Часть проекта [NATL](../../README.md).

## Что делает

- **Записывает** клики и ввод в браузере (Chromium под управлением Playwright).
- **Сохраняет** сценарий файлом `tests/<имя>.yaml` в папку проекта.
- **Показывает** список сценариев, вкладки, редактор с автосохранением.
- **Запускает** тот же файл через `@natl/core` и показывает шаги, статусы
  и скриншоты до и после каждого действия.
- **Пишет журнал** с уровнями и файлом, чтобы ошибку можно было разобрать
  после закрытия приложения.

## Требования

- Windows 10/11 x64 (сборки Linux и macOS — в плане).
- Node.js 20+ для сборки из исходников.
- Chromium для записи и прогона скачивается сам при первом запуске (см. ниже).

## Разработка

```
npm install
npm start
```

## Браузер

Chromium (~280 МБ) скачивается при первом запуске в папку данных приложения:
`%APPDATA%\NATL\browsers`. Прогресс виден в диалоге: проценты, имя файла,
сколько скачано. Если связь оборвалась — «Повторить»; попыток три, паузы 1 и 3 с.
Диалог можно закрыть: приложение работает, но запись и прогон скажут, что
браузера нет.

Системный Playwright больше не нужен: `npm install` ничего не докачивает.
Для разработки и CI есть отдельная команда:

```
npm run browser:install
```

Она ставит браузер в `apps/desktop/.browsers` (папка в `.gitignore`).
Переменная `PLAYWRIGHT_BROWSERS_PATH` переопределяет папку и в приложении,
и в скрипте — удобно для общего кэша на машине сборки.

Корпоративная сеть:

- прокси — задайте `HTTPS_PROXY` (и `HTTP_PROXY`) с адресом прокси;
- антивирус или прокси подменяет сертификат — укажите корневой сертификат
  в `NODE_EXTRA_CA_CERTS`;
- совсем нет интернета — скачайте браузер на другой машине
  (`npm run browser:install`), затем скопируйте папку `browsers`
  в `%APPDATA%\NATL\browsers`.

## Сборка установщика

```
npm run build
```

Результат в `dist/`: `NATL Setup <версия>.exe` (установщик) и `NATL <версия>.exe`
(портативная версия).

## Проверки

```
npm run test:natl    # юнит-тесты конвертера, хранилища, прогона, журнала, браузера
npm run smoke:natl   # реальный прогон на офлайн-фикстуре
npm run smoke:record # запись в headless-браузере и повторный прогон
```

Сквозные проверки работают без интерфейса: локальный сервер отдаёт фикстуру
из `examples/fixtures`, сценарий пишется во временную папку и запускается
тем же кодом, что и приложение. Если браузера ещё нет, smoke скачает его
сам — в `.browsers` или в папку из `PLAYWRIGHT_BROWSERS_PATH`.

## Структура

```
electron/
  natl/          запись, прогон, YAML, журнал
  ipc/           мост между окном и системой
  store/         хранилище старой модели (импорт старых папок)
frontend/
  screens/       Scenarios, Logs
  components/    диалог записи, заголовок окна, граница ошибок
```

## Ограничения текущей версии

- Windows x64, сборка без подписи.
- Chromium скачивается при первом запуске: без интернета запись и прогон не работают.
- Пароли записываются в YAML как есть — заменяйте на переменную перед коммитом.
- iframe, новые вкладки и загрузка файлов не записываются.
