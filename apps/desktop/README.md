# NATL Desktop

Приложение для записи и запуска UI-тестов. Часть проекта [NATL](../../README.md).

## Что делает

- **Записывает** клики и ввод в браузере (Chromium под управлением Playwright).
- **Сохраняет** сценарий файлом `tests/<имя>.yaml` в папку проекта.
- **Показывает** список сценариев, вкладки, редактор с автосохранением.
- **Запускает** тот же файл через `@natl/core` и показывает шаги, статусы
  и скриншоты до и после каждого действия.
- **Пишет журнал** с уровнями и файлом, чтобы ошибку можно было разобрать
  после закрытия приложения.

## Требования

- Windows 10/11 x64 (сборки Linux и macOS — в плане).
- Node.js 20+ для сборки из исходников.
- Браузеры Playwright: `npx playwright install chromium`.

## Разработка

```
npm install
npm start
```

## Сборка установщика

```
npm run build
```

Результат в `dist/`: `NATL Setup <версия>.exe` (установщик) и `NATL <версия>.exe`
(портативная версия).

## Проверки

```
npm run test:natl    # юнит-тесты конвертера, хранилища, прогона, журнала
npm run smoke:natl   # реальный прогон на офлайн-фикстуре
npm run smoke:record # запись в headless-браузере и повторный прогон
```

Сквозные проверки работают без интерфейса: локальный сервер отдаёт фикстуру
из `examples/fixtures`, сценарий пишется во временную папку и запускается
тем же кодом, что и приложение.

## Структура

```
electron/
  natl/          запись, прогон, YAML, журнал
  ipc/           мост между окном и системой
  store/         хранилище старой модели (импорт старых папок)
frontend/
  screens/       Scenarios, Logs
  components/    диалог записи, заголовок окна, граница ошибок
```

## Ограничения текущей версии

- Windows x64, сборка без подписи.
- Браузеры Playwright не входят в установщик: на новой машине их ставят отдельно.
- Пароли записываются в YAML как есть — заменяйте на переменную перед коммитом.
- iframe, новые вкладки и загрузка файлов не записываются.
